# 素材来源与授权

| 素材 | 来源 | 授权 | 用在哪里 |
|---|---|---|---|
| 竹子、纸槽、石臼、竹帘、辘轳车、瓷窑、染缸、烟灯、墨模、砚台、老学者 | Seedream 5.0 参考图（`../../assets_lab/tiangong/prompts.tsv`）+ Doubao-Seed3D 2.0，`prep_ai.py` 减面。模型生成前，游戏里用代码搭的简单形状代替 | AI 生成，本项目自有 | 四个工位、客人 |
| 作坊（地板、白墙、格子窗、柱子、瓦檐、灯笼、转台） | 代码里用几何体和程序贴图搭建（`render/WorkshopView.kt`）；地板、墙、瓦的 AI 贴图生成后自动替换 | 本项目自有 | 作坊 |
| 成品（纸、瓷坯、扎染布、墨锭、春联） | 按玩家的操作程序生成：瓷坯由四道轮廓旋转成形，扎染花纹由折法和扎绳算出，纸的瑕疵随品质变化 | 本项目自有 | 作品和展柜 |
| 音效（砍竹、舂捣、节拍、窑火、蘸水等） | `../../tools/sfx_synth.py` 程序合成 | 本项目自有 | 音效 |
| 背景音乐《Orient Peace Valley》（tozan） | opengameart.org/content/orient-peace-valley | CC0 | 背景音乐来自 OpenGameArt，均为 CC0，响度统一到 -20 LUFS（`../../assets_lab/music_r5.sh`）；首选和备选的试听版在 `docs/音乐候选/`：《Asianoriental1》（tozan）、《Menu Music》（wipics） |
| 《天工开物》引文 | 明代宋应星著（1637 年） | 公有领域 | 天工开物图谱 |
| 图标、海报 | 老学者、辘轳车、瓷窑、染缸的参考图抠图合成（`../../tools/store_art.py`） | 本项目自有 | 商店素材、应用图标 |
